锚点质量

标注者锚点 已比对 / 就绪 效价 MAE唤醒 MAE 效价 r唤醒 r

锚点 = 你在 REF 账号上两维都标完的正式子任务（训练子任务除外）；「就绪」是其中分给这个人的， 「已比对」是他也交了的。MAE 是两条曲线平均差多少（量程 -1…1，越小越接近）； r 是走势相关（任一边几乎不动时不算）。平均 MAE 超过全组中位数 1.5 倍、且比对 ≥ 5 条的标红。 这个面板计算较重，不自动刷新。

每日抽查

从这个人当天（芬兰时间）两维都交了的条目里随机抽。点播放，曲线上的竖线跟着素材走； 实线是他的，虚线是你的参考（只有锚点才有）。红色小标是自动提示：几乎不动、量程很窄（<0.2）、 同一维重标 ≥3 版。「正常 / 存疑 / 作废」只追加一条处置记录，不删数据，标注者看不到。
